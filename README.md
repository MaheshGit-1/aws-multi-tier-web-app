## 📌 Project Overview

This project demonstrates the deployment of a secure and scalable multi-tier web application on Amazon Web Services (AWS). The infrastructure is designed following AWS Well-Architected Framework best practices with secure networking, EC2 instances, Apache Web Server, and Security Groups.

---

## 🏗️ Architecture

The application is deployed inside a custom AWS Virtual Private Cloud (VPC) using secure networking principles.

## 🚀 Deployment Steps

- Create VPC
- Create Public Subnet
- Configure Route Tables
- Attach Internet Gateway
- Launch EC2 Instance
- Configure Security Groups
- Install Apache
- Deploy Web Application
